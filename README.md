# willow

*A handcrafted font, showcased through through an interactive website.*

## About

helloo there!! I'm Pia, and this was my first time making a real website. I wanted to do something simple, but still include interactive elements with some level of complexity. I hope this website allows you to explore the font in a fun way.

---

## Features

- Animated landing page
- Character set preview
- Interactive text preview
- Font size adjustment
- Letter spacing controls
- Font personality section
- FAQ section
- Back-to-top footer
- Responsive layout
- Smooth animations and transitions

---

## Built With

- HTML5
- CSS3
- JavaScript

---

## What I Learned

This project taught me a lot about front-end development, including:

- Structuring larger HTML projects
- Building responsive layouts with Flexbox
- Styling reusable UI components
- Creating interactive elements with JavaScript
- Working with custom fonts using `@font-face`
- CSS transitions and animations
- Organizing files for a larger project
